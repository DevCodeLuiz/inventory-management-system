
# 📦 Inventory Management System

A web-based inventory management system designed to simplify product management and stock control.

## 🚀 About the Project

This project focuses on creating an organized and practical solution for managing inventory, tracking products, and monitoring stock levels.

## ✨ Features

- Product registration and management
- Inventory control
- Stock entry and exit tracking
- Product quantity monitoring
- Minimum stock management
- Organized product information

## 🛠️ Technologies

- JavaScript
- HTML5
- CSS3
- Node.js

## 🎯 Objective

Develop a practical inventory management solution while improving software development skills and applying programming concepts.
